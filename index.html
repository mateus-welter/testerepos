Sistema de Cadastro de Motores

Documentação técnica do protótipo CRUD desenvolvido em memória para gestão de especificações técnicas de motores elétricos.

Arquitetura e Funcionamento do Código

Para fins de validação de lógica e testes rápidos sem dependência de bancos de dados externos, a aplicação foi estruturada de forma monolítica em um único arquivo, dividindo responsabilidades em funções específicas:

motores = []

Array (lista) global que atua como banco de dados em memória, armazenando cada motor como um dicionário com chaves estruturadas.

gerar_novo_id()

Verifica o último registro inserido na lista e incrementa automaticamente o identificador único (Auto-Incremento).

cadastrar_motor()

Coleta dados via terminal, valida entradas numéricas (CV e RPM) com blocos try/except e anexa o registro à lista.

listar_motores() & buscar_motor()

Percorre o array exibindo todos os registros ou filtrando resultados por ID exato ou correspondência parcial no nome do modelo.

atualizar_motor()

Localiza o registro pelo ID e permite edição seletiva dos campos, mantendo os valores originais caso o usuário pressione Enter em branco.

remover_motor()

Identifica o índice do motor desejado através da função enumerate() e remove o item da memória utilizando .pop().

Modelo de Dados e Implementação

Cada motor cadastrado segue a estrutura de dicionário abaixo, pré-populada na inicialização com modelos de referência da linha industrial:

{
    "id": 1,

    "fabricante": "WEG",
    "potencia_cv": 10.0,
    "rotacao_rpm": 1750,
    "tensao_v": "220/380V"
